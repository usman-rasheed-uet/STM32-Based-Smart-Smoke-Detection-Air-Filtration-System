# STM32-Based-Smart-Smoke-Detection-Air-Filtration-System
An embedded air-quality monitoring and filtration system based on the STM32F103C8T6 microcontroller.  The system uses MQ-2 and MQ-135 sensors to detect smoke and changes in air quality. Based on sensor readings, it automatically controls a two-stage fan system while providing real-time information through an SSD1306 OLED display.
